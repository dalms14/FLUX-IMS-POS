# FLUX Evaluation Working Draft

The current working document is [FLUX_EVALUATION_CORRECTED.docx](../../artifacts/evaluation/FLUX_EVALUATION_CORRECTED.docx). Its existing filename is retained for traceability; it does not indicate final adviser approval.

## Current document structure

- Part A contains 25 task-based Pass/Fail test cases, labeled Alpha system evaluation.
- Part B contains 45 rating statements, labeled Beta system evaluation. It covers the nine ISO/IEC 25010:2023 product quality characteristics and an additional overall evaluation section.
- The rating scale printed in Part B is 4 Strongly Agree, 3 Agree, 2 Disagree, and 1 Strongly Disagree.

## Review status

The researchers reported that the adviser may have intended the software quality categories to be assigned to technical evaluators instead of the current Beta form. The exact feedback has not yet been confirmed. Discussions also considered using selected relevant characteristics rather than automatically including all nine.

The recommended next revision is to distinguish developers' recorded test results, an IT expert quality questionnaire, and evaluation by the cafe's intended users. The current document still mixes technical review items, such as source-code maintainability, with user-facing ratings. Some statements also need to be reassigned to more appropriate characteristics.

No revised allocation of Alpha/Beta labels or final selection of characteristics has been applied to this document. Confirm the intended respondent groups, selected characteristics, scale, and scoring method with the adviser before collecting responses. Alpha/Beta labels and questionnaire response formats should be described separately in the study methodology.

Earlier document iterations and rendering previews remain local working files. The other group's questionnaire was used only as a discussion reference and is not part of the FLUX deliverable.
